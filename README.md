# @t8ngs/fs

Este projeto é uma biblioteca de manipulação de sistema de arquivos para Node.js, inspirada no estilo e na simplicidade do framework Japa.

## Instalação

Para instalar o pacote, execute:

```bash
npm install @t8ngs/fs
```

## Uso

Importe e utilize as funções principais:

```typescript
import { assertDir, assertFile } from '@t8ngs/fs';

// Exemplo de uso
assertDir('caminho/do/diretorio');
assertFile('caminho/do/arquivo');
```

## Baseado no Japa

Este projeto foi desenvolvido inspirado no Japa, focando em simplicidade, clareza e facilidade de uso para testes e manipulação de arquivos.
